# 5편: 생각 먼저, 행동은 나중에 — 계획하는 에이전트

일주일 점심을 맡기는 두 가지 방법을 비교해요.
- **하루씩**: 매일 아침 에이전트를 새로 불러서 오늘 점심만 정해요 (1~4편 루프 그대로)
- **계획 먼저**: 월~금 계획표를 먼저 받고 → **코드가 검사**하고 → 통과하면 하루씩 실행해요. 틀어지면 남은 날만 다시 계획해요.

| 파일 | 내용 |
|---|---|
| `week_tools.py` | 식당 7곳(가격·평점), 한 주 장부(`Week`), 모델 호출 간격 조절(무료 한도) |
| `week_daily.py` | 방식 A 하루씩: 매일 `get_week_status` 도구로 쓴 돈·남은 예산을 확인하며 오늘만 고름 |
| `week_plan.py` | 방식 B 계획 먼저: `make_plan`(계획표 요청) · `check_plan`(형식·모르는 식당·휴무·예산·중복 검사) · `count_possible`(가능한 계획이 있는지 코드가 먼저 세기) · `run_week`(실행, 휴무면 남은 날만 다시 계획) |
| `compare.py` | 두 방식을 같은 과제로 5번씩 (`python compare.py`, 금요일 손님 조건은 `python compare.py future`) |
| `replan.py` | 수요일에 계획한 식당이 휴무일 때 다시 계획 (`python replan.py`, `python replan.py 38000`) |
| `실행기록_*.txt` | 2026-11-16에 실제로 실행한 결과 (모델: gemini-flash-lite-latest) |

## 실행

```bash
cd 05-planning
python week_daily.py            # 하루씩 한 주
python week_plan.py             # 계획 먼저 한 주
python compare.py               # 5번씩 비교 (호출 사이 4.2초씩 쉬어서 몇 분 걸려요)
python compare.py future        # 금요일 손님 2인분 · 예산 40,000원
python replan.py 38000          # 수요일 휴무 → 남은 날만 다시 계획
```

준비: `pip install google-genai`, 환경변수 `GOOGLE_API_KEY`에 Gemini API 키

> ⚠️ 무료 한도는 모델마다 달라요. 제가 실행할 때(2026-11) Flash Lite 모델은 무료로 **1분에 15번**까지라 `week_tools.py`의 `generate`가 호출 사이를 4.2초씩 띄워요.
> 모델의 답은 실행할 때마다 달라요. 결과가 영상과 똑같지 않아도 이상한 게 아니에요.

## 실험 결과 (실행 기록 참고)

| 실험 | 하루씩 | 계획 먼저 |
|---|---|---|
| 기본 (합계 35,000원 이하, 같은 식당 한 번만), 각 5번 | 5/5 지킴 · 모델 호출 평균 10.2번 | 5/5 지킴 · 평균 2.0번 |
| 금요일 손님 2인분 (예산 40,000원), 각 5번 | 3/5 지킴 · **2번은 경고 없이 예산 초과** (40,600원·41,800원) | 3/5 지킴 · 2번은 계획이 검사를 통과 못 해 **실행하지 않고 멈춤** (어긴 채 실행 0번) |

다시 계획(수요일 휴무):
- 가능성 검사를 넣기 전: 3번 모두 다시 계획 실패 — 계산해 보니 남은 돈·식당으로 **가능한 계획이 0개**였어요 (`실행기록_다시계획_가능성검사전.txt`)
- 가능성 검사 후, 예산 35,000원: 2번은 '가능한 계획 0개'를 코드가 바로 잡아 모델을 부르지 않고 사람에게 넘김
- 예산 38,000원: 2번은 다시 계획 성공 (37,000원·35,800원)

> 참고: 모델이 처음 세운 계획에는 같은 식당을 두 번 넣거나(백반집), 고쳐 달라고 하면 요일 표 대신 목록으로 답하는 일이 잦았어요. `check_plan`이 전부 잡아냈어요.

## 꼭 기억할 세 가지
1. 계획 먼저는 호출을 아끼고, 미리 알 수 있는 조건을 챙긴다
2. 계획은 모델이 세워도, 검사는 코드가 한다
3. 틀어지면 남은 날만 다시 계획하고, 답이 없으면 사람에게 넘긴다
