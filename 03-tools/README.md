# 3편: 모델이 잘 쓰는 도구는 따로 있다

1편 과제였던 **'걸어서 몇 분' 도구**의 정답 풀이예요.
모델은 함수 안의 코드를 보지 못하고 **이름, 설명, 매개변수**만 봐요. 그래서 도구의 이름과 설명이 곧 프롬프트예요.
같은 도구를 버전별로 바꿔 가며 5번씩 돌려서, 무엇이 결과를 바꾸는지 직접 세어 봤어요.

| 파일 | 내용 |
|---|---|
| `walk_agent.py` | 1편 점심 에이전트 + '걸어서 몇 분' 도구 세 버전. v1 `walk(r)` 설명 '시간' / v2 `get_walking_minutes` 좋은 설명 / v3 좋은 설명 + 친절한 실패 메시지 |
| `experiment.py` | 실험 1: 나쁜 도구(v1)와 좋은 도구(v3)를 같은 질문으로 5번씩 |
| `experiment2.py` | 실험 2: 이름까지 지운 `t(x)`, 초 단위 반환, '김밥 천국' 띄어쓰기 질문(에러를 내는 v2 vs 친절한 메시지 v3) |
| `experiment3.py` | 실험 3: 식당마다 하나씩 묻는 대신 일 단위로 묶은 도구 `find_nearby_restaurants` |
| `confirm_agent.py` | 되돌릴 수 없는 예약 도구는 실행 전에 사람에게 y/n 확인 |
| `*실행기록*.txt` | 2026-11-03에 실제로 실행한 결과 (모델: gemini-flash-lite-latest) |

## 실행

```bash
cd 03-tools
python walk_agent.py v1        # 나쁜 도구
python walk_agent.py v3        # 좋은 설명 + 친절한 실패 메시지
python walk_agent.py v2 "'김밥 천국'까지 걸어서 몇 분 걸려?"   # 질문을 바꿔서
python experiment.py           # 5번씩 돌려서 정답 횟수 세기 (모델 호출이 많아요)
python confirm_agent.py        # 예약 직전에 y/n을 물어봐요
```

준비: `pip install google-genai`, 환경변수 `GOOGLE_API_KEY`에 Gemini API 키

> ⚠️ 무료 한도는 모델마다 달라요. 제가 실행할 때(2026-11) Flash Lite 모델은 무료로 **1분에 15번**까지였어요. `experiment*.py`는 모델을 여러 번 부르니 한도에 걸리면 잠깐 쉬었다 하세요.
> 모델의 답은 실행할 때마다 조금씩 달라요. 결과가 영상과 똑같지 않아도 이상한 게 아니에요.

## 실험 결과 (각 5번, 실행 기록 참고)

| 실험 | 결과 |
|---|---|
| 대충 만든 도구 `walk(r)`, 설명 '시간' | 5번 중 5번 정답 (이름 walk + 질문의 '걸어서'로 짐작) |
| 좋은 도구 v3 | 5번 중 5번 정답 (5번 합계 모델 호출은 좋은 도구 18번, 나쁜 도구 16번으로 오히려 조금 많음) |
| 이름까지 지운 `t(x)` | 5번 중 2번 정답 |
| '김밥 천국' 띄어쓰기 + 에러를 내는 v2 | 5번 모두 KeyError로 프로그램 중단 |
| 같은 질문 + 친절한 실패 메시지 v3 | 10번 중 8번 스스로 고쳐서 정답 |
| 일 단위로 묶은 도구 (각 3번) | 도구 실행 9~10번 → 4번, 답은 모두 분식나라 |

※ `experiment_실행기록_2차.txt`의 '걸음 도구 호출 예' 칸은 출력 필터 실수로 다른 도구 줄이 섞였어요. 정답·중단 횟수는 정상이에요.

## 꼭 기억할 세 가지
1. 모델은 함수 코드를 못 본다. 이름과 설명이 곧 프롬프트다
2. 실패하면 멈추지 말고, 고칠 방법을 담아 돌려준다
3. 도구는 적고 분명하게. 되돌릴 수 없는 일은 사람에게 묻는다
