# 2편: AI는 사실 아무것도 기억 못 해 — 에이전트에게 기억 붙이기

모델은 요청 하나에 답 하나를 내고 끝나요. **기억은 모델 안이 아니라 바깥에 있어요.**
이번 편에서는 1편 점심 에이전트에 기억을 붙여서, 어제 먹은 메뉴를 피해 추천하게 만들어요.

| 파일 | 내용 |
|---|---|
| `forgetful_chat.py` | 실험: 같은 질문을 '기록 없이' 한 번, '대화 기록과 함께' 한 번 보내 보기 (단기 기억) |
| `memory_agent.py` | 기억하는 점심 에이전트. 1편 코드에 기억 도구 2개(`recall_meals`, `save_meal`)와 기억 규칙(지시문)을 더했어요 (장기 기억) |
| `*_실행기록.txt` | 2026-10-22에 실제로 실행한 결과 |
| `lunch_agent_1편_다시실행_기록.txt` | 비교용: 기억 없는 1편 에이전트는 다시 돌려도 또 김밥천국 |
| `memory_agent_한도초과_기록.txt` | 실습 중 실제로 만난 무료 한도 초과(429) 에러 |

## 실행

```bash
cd 02-memory
python forgetful_chat.py
python memory_agent.py 2026-10-21   # '어제'를 만들기
python memory_agent.py 2026-10-22   # 오늘: 어제 먹은 곳을 피해서 추천
```

실행하면 같은 폴더에 `lunch_history.json`(점심 일기장)이 생겨요. 열어서 직접 보고, 지우고, 고쳐 봐도 돼요.

> ⚠️ 무료 한도는 모델마다 달라요. 제가 실행할 때(2026-10) Flash Lite 모델은 무료로 **1분에 15번**까지였어요. 연달아 실행할 땐 잠깐 쉬었다 하세요.

## 꼭 기억할 세 가지
1. 모델은 아무것도 기억하지 못한다. 기억은 바깥에 있다
2. 단기 기억은 대화 기록, 장기 기억은 파일. 다 넣지 말고 필요한 것만 골라 넣는다
3. 기억도 도구다. 언제 꺼내고 언제 적을지 모델에게 맡길 수 있다

2. 식당 말고 '같이 먹은 사람'도 기억하게 만들어 보세요. `save_meal`에 매개변수 하나만 더하면 돼요
