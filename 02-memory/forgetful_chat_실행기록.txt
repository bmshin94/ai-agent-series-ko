# 2026-10-22 실제 실행 기록 (모델: gemini-flash-lite-latest, 모델 호출 3회)
$ python forgetful_chat.py
나: 어제 점심은 김밥천국에서 먹었어. 한 줄로만 대답해 줘.
AI: 어제 김밥천국에서 점심을 드셨군요!

[기록 없이] 나: 내가 어제 점심 어디서 먹었다고 했지? 한 줄로만 대답해 줘.
AI: 죄송하지만, 저는 이전 대화 내용을 기억하지 못해 어제 점심을 어디서 드셨는지 알 수 없습니다.

[기록과 함께] 나: 내가 어제 점심 어디서 먹었다고 했지? 한 줄로만 대답해 줘.
AI: 어제 김밥천국에서 드셨다고 하셨습니다.
