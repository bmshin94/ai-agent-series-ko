# 1편: AI 에이전트, 사실 while 문 하나야

AI 에이전트의 정체는 **생각 → 행동 → 관찰**을 반복하는 반복문이에요.

| 파일 | 내용 |
|---|---|
| `chatbot.py` | 비교용 '그냥 챗봇'. 모델을 한 번 부르고 끝나요 (지갑에 얼마 있는지 모르니 추측으로 대답) |
| `lunch_agent.py` | 점심 결정 에이전트. 도구 3개(식당 목록·지갑·계산기)를 스스로 골라 쓰며 결론까지 반복해요 |
| `*_실행기록.txt` | 2026-10-14에 실제로 실행한 결과 |

## 꼭 기억할 세 가지
1. 에이전트는 새로운 AI가 아니라 LLM을 감싼 **구조**다
2. 모델은 도구를 **요청**할 뿐이고, 실행은 우리 코드가 한다
3. 반복에는 반드시 한계(`MAX_STEPS`)를 둔다

## 직접 해보기
1. `check_wallet()`이 15000을 돌려주게 바꿔서 다시 실행해 보세요. 추천이 어떻게 달라지나요?
2. 식당까지 걸어서 몇 분 걸리는지 알려주는 도구를 하나 더 만들어 보세요. 함수를 만들고 `TOOLS` 목록에만 넣으면, 루프 코드는 그대로 둬도 에이전트가 알아서 써요. (정답은 3편에서!)
